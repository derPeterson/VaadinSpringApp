# Anbieterressourcen
Diese Markenbilder sind ausschließlich für die jeweiligen Anmeldebuttons bestimmt.
Sie werden lokal ausgeliefert. Die allgemeinen Anwendungssymbole bleiben Lucide.

- `google.png`: offizielles Google-G aus [Google Identity](https://developers.google.com/static/identity/images/g-logo.png).
  Verwendung nach [Google-Brandingvorgaben](https://developers.google.com/identity/branding-guidelines).
- `microsoft.svg`: offizielles Microsoft-Zeichen aus [Microsoft Identity](https://learn.microsoft.com/en-us/entra/identity-platform/media/howto-add-branding-in-apps/ms-symbollockup_mssymbol_19.svg).
  Verwendung nach [Microsoft-Brandingvorgaben](https://learn.microsoft.com/en-us/entra/identity-platform/howto-add-branding-in-apps).
- `GoogleSans-latin.woff2`: Google Sans, lateinische Schriftzeichen, lokal für den Google-Button.
  Lizenz: `GoogleSans-OFL.txt`, aus [google/fonts](https://github.com/google/fonts/tree/main/ofl/googlesans).
