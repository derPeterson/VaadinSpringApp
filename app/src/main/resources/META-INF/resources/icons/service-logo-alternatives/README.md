# Aufbewahrte Service-Logos

Bewusst aufbewahrte Alternativen aus den gemeinsamen Google-Stitch-Logorunden
zum Projekt „Workflow testen – Cosmos“. A–J und L–O sind keine aktiven
Anwendungsressourcen. `service-logo_alt.png` ist das bisherige Anwendungslogo.
Sie bleiben für eine spätere gezielte Auswahl erhalten.

Das ausgewählte Motiv K heißt im übergeordneten Ordner `service-logo.svg`.
`service-logo.png` ist dessen transparente PNG-Ausgabe für HTML-E-Mails und
PWA-Installationssymbole. Header und Favicon verwenden das SVG. Die Anwendung
lädt keine Alternativen automatisch.
