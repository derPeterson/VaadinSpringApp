# Automatisierte Browsertests

Die aktuelle Anleitung für Java, JUnit, Playwright und Allure steht direkt im [Testordner](../../browser-tests/README.md).

Der bestätigte [Designstandard](../design-standard.md) und die aktuelle
[Abdeckung](../../browser-tests/abdeckung.md) beschreiben den Redesign-Abschluss.
Dauerhafte Ergebnisse wichtiger Abschlüsse: [Meilensteine](../meilensteine/README.md).
Lokale Laufordner sind bereinigbare Diagnoseausgaben.
Optionale Messung des serverseitigen Java-Codes: `browser-tests/run.ps1 -Coverage`.
