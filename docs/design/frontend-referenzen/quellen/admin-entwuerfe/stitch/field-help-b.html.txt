<div class="grid grid-cols-1 md:grid-cols-3 gap-6 text-xs text-slate-300 leading-relaxed">
<!-- Spalte 1: Vorteile -->
<div class="bg-[#050811] p-4 rounded-lg border border-emerald-950/60 space-y-2">
<h4 class="font-bold text-emerald-400 flex items-center gap-1.5 uppercase tracking-wider text-[11px]">
<svg class="w-4 h-4" fill="none" stroke="currentColor" viewbox="0 0 24 24"><path d="M5 13l4 4L19 7" stroke-linecap="round" stroke-linejoin="round" stroke-width="2"></path></svg>
            Vorteile (Pros)
          </h4>
<ul class="space-y-1.5 list-disc list-inside text-slate-300">
<li><strong>Keine Overlay-Konflikte:</strong> Im Gegensatz zu Popovers verdeckt die Hilfe keine darunterliegenden Felder oder Buttons.</li>
<li><strong>Optimale Scanbarkeit:</strong> Standardansicht bleibt extrem kompakt; fortgeschrittene Syntax (z.B. Platzhalter) wird erst bei Bedarf sichtbar.</li>
<li><strong>Mobilfreundlich:</strong> Integriert sich linear in den DOM-Fluss ohne Z-Index-Berechnungen oder Viewport-Clipping.</li>
</ul>
</div>
<!-- Spalte 2: Nachteile / Herausforderungen -->
<div class="bg-[#050811] p-4 rounded-lg border border-amber-950/60 space-y-2">
<h4 class="font-bold text-amber-400 flex items-center gap-1.5 uppercase tracking-wider text-[11px]">
<svg class="w-4 h-4" fill="none" stroke="currentColor" viewbox="0 0 24 24"><path d="M12 9v2m0 4h.01m-6.938 4h13.856c1.54 0 2.502-1.667 1.732-3L13.732 4c-.77-1.333-2.694-1.333-3.464 0L3.34 16c-.77 1.333.192 3 1.732 3z" stroke-linecap="round" stroke-linejoin="round" stroke-width="2"></path></svg>
            Herausforderungen (Cons)
          </h4>
<ul class="space-y-1.5 list-disc list-inside text-slate-300">
<li><strong>Layout-Shift (Reflow):</strong> Beim Aufklappen verschieben sich nachfolgende Zeilen nach unten (kann bei schneller Bedienung ungewohnt wirken).</li>
<li><strong>Asymmetrie bei 2-Spalten:</strong> Wird nur ein Feld in der Zeile ausgeklappt, entsteht ein Höhenunterschied zur Nachbarspalte.</li>
</ul>
</div>
